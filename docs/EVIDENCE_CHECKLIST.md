## How to Take Screenshots

### On Windows:
- **Full page**: `Win + Shift + S` → drag over the screen area
- **Active window**: `Alt + PrtScn`
- **Browser full page**: In Chrome DevTools → `Ctrl+Shift+P` → type "screenshot" → "Capture full size screenshot"

### Mobile Screenshots (Chrome DevTools):
1. Open Chrome DevTools (`F12`)
2. Click the device toggle icon (📱) or press `Ctrl+Shift+M`
3. Set device to "iPhone 14 Pro" (390px) or "Galaxy S20" (360px)
4. Take screenshot via DevTools menu → "Capture screenshot"
