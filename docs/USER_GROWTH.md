## 🧑‍💻 Onboarding Instructions (User Steps)

1. Install [Freighter Wallet](https://freighter.app/) browser extension
2. Open Freighter → Settings → Switch network to **Testnet**
3. Get free testnet XLM: [Stellar Friendbot](https://lab.stellar.org/#account-creator)
4. Visit the app: [https://level6-2mgt.vercel.app/](https://level6-2mgt.vercel.app/)
5. Connect wallet → Book a Cylinder (testnet only — no real money)
6. Fill the feedback form: [Google Form](https://docs.google.com/forms/d/e/1FAIpQLScGh_ghH6mjY2NRtHgApPG4fKj_71iciy1Dr8CQaw_Q2LTqSQ/viewform?usp=publish-editor)
